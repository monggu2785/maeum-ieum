# 마음이음 · 화산중학교 GitHub Pages

이 폴더의 내용은 GitHub 저장소 `maeum-ieum` 최상단에 그대로 업로드합니다.

## 구조

- `index.html`
- `css/style.css`
- `js/schools.js`
- `js/bridge-api.js`
- `js/app.js`

`js/schools.js`에는 현재 화산중학교 Apps Script 웹앱 `/exec` 주소가 이미 반영되어 있습니다.

## GitHub Pages

Settings → Pages → Deploy from a branch → `main` / `(root)` → Save

배포 후 기존 파일 캐시가 남으면 Ctrl+F5로 새로고침합니다.
